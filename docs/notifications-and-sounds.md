# Notifications and sounds

## Notifications

Mixdown uses notifications to:

- say a note is ready (**Note Ready**), with **Open** to show the note in Mixdown and **Show in
  Finder** for its file,
- confirm copying a transcript,
- offer **Restore** after deleting a note,
- ask about calls, or say it's recording one. See [Recording calls](calls.md#call-detection).
- ask **Still Recording?** when no one has spoken for a while, with **Stop Recording** and **Keep
  Recording**. See [Recording](recording.md#while-recording).

To turn them all off, untick **Settings → Notifications → Show notifications**. Deleted notes can
then only be restored from the Trash. Automatic call recording keeps working; the menu bar icon is
then the only sign of it.

If notifications are off for Mixdown in System Settings, **Settings → Notifications** says so and
has a button to open them.

## Sounds

Short sounds mark these moments, so you can tell without looking:

| Moment | Default sound |
| ------ | ------------- |
| Recording starts | Tink |
| Recording pauses | Bottle |
| Recording resumes | Morse |
| Recording stops | Pop |
| Note is ready | Glass |
| Something goes wrong (recording couldn't start or stopped early, or a note couldn't be finished) | Basso |

Pick a different macOS sound, or **None**, for each under **Settings → Notifications → Sounds**;
choosing one plays it. Untick **Play sounds** to turn them all off.

The sounds aren't recorded from system audio, but without headphones your microphone may hear the
start sound.
